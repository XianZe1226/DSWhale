# 验证范围

版本：0.2.0a2，日期：2026-10-28。当前发布候选的测试结果见 [GitHub Actions](https://github.com/XianZe1226/DSWhale/actions)；本页不把旧版本 CI 当作本版验收。

## 自动化验证

测试不需要 QQ、Cookie 或模型密钥。Python 覆盖主人/群隔离、免打扰与预算、持久任务、发送不确定不重放、真实 AstrBot SDK、LivingMemory 只读集成、真实 FFmpeg、字幕与媒体边界、安装/备份/恢复、Windows Job Object 后代进程回收、QQ 喊话任务、笔记追问和长视频下载保护。Node 覆盖上游工具、调度器、账号/额度保护、同源/令牌和宿主适配。

CI 在 Linux、macOS、Windows Server 2022 上执行测试、构建和安装包；Windows 额外使用系统 PowerShell 5.1，在中文与空格路径中解压完整源码、全新安装、重复升级。Windows 专属进程清理测试只在 Windows 内核运行，macOS 本地跳过。宿主依赖有一条 audioop 弃用提示，因此固定 Python 3.12，不自动切到 3.13。

## 人工验证与边界

macOS 已验证普通 QQ 私聊、反向 WebSocket 与重连、主人绑定、聊天/图片模型、LivingMemory 配置、短视频观察、B站扫码与互关、定时活动、主人 B站私信处理、QQ 喊话自主选题与一次推荐、追问已保存视频笔记，以及独立官方 QQ 与机器人实例同时运行。个人角色、账号、原始聊天和原始运行记录不随发布分发。

该结果不保证每个模型、视频、登录状态或平台接口都可用。未完成真实账号的 Windows 10/11 笔记本验收，也未完成所有抖音、STT/TTS、长期记忆删除/跨版本索引兼容和长期无人值守场景。CI 服务器安装通过不等于已替用户扫码验证 QQ/B站，更不保证账号不受平台限制。

## 新机器验收

1. 普通主人 QQ 私聊能得到回复，两个客户端登录账号正确。
2. `/fish status` 的主人、图片模型与开关正确；不要将返回的身份信息截图公开。
3. 短视频链接返回明确的字幕/画面证据范围。
4. LivingMemory 控制台可查到自己的记忆；测试一次召回、纠正/删除，不更换未兼容的 Embedding 维度。
5. 完成一次低频自主选题，收到推荐后追问内容，确认使用笔记而非重复开任务。
6. 如需 B站私信，单独验证监听、互关与自动发送授权。
7. 停宿主后备份并恢复到非唯一的数据副本；确认私人设定、记忆和预算仍在。

任何反馈都先脱敏，不上传备份、Cookie、私聊、完整环境或个人提示词。
