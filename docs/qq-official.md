# QQ 官方机器人：第一次使用

适合希望在一台电脑上同时使用个人 QQ 和大肥鱼的用户。此方式使用 QQ 开放平台的机器人接口，不需要 NapCat、不需要登录普通 QQ 机器人小号，也不修改个人 QQ。Windows、macOS 和 Linux 使用相同流程。

## 准备应用

1. 安装 DSWhale，在「运行环境」完成准备。所需 Python、Node.js、AstrBot 和媒体工具由应用管理。
2. 打开「QQ 连接」，查看 **QQ 官方机器人** 页签。首次还没有官方机器人时，先启动对话服务，再按下一节创建；已有机器人可在「连接管理」单独启用。它和普通 QQ 小号可以同时在线，查看页签不会停止 NapCat，也不会改变互动开关。
3. 按页面按钮启动对话服务，再点击「配置官方机器人」。机器人配置会在当前窗口打开。
4. 如果控制台要求登录，用顶部「控制台首次口令」查看初始密码，完成登录并设置自己的密码。已有安装使用原密码，不要重复初始化或导入旧备份。

## 创建或接入机器人

推荐使用 AstrBot 已有的扫码创建功能：

1. 在内置控制台「机器人」页面点击「创建机器人」。
2. 选择 **QQ 官方机器人（WebSocket）**，选择 **扫码一键创建**。
3. 用手机 QQ 扫描二维码并确认。操作会通过 QQ 开放平台创建机器人；AstrBot 将保存对应 AppID 与 AppSecret。
4. 确认机器人已启用并保存。为这个连接保留固定的平台 ID，后面的私聊绑定会用到它。
5. 按页面提示打开 QQ 开放平台的机器人页面，使用「扫码聊天」进入与机器人的消息列表私聊。

已有官方机器人时，可选择手动填写，在内置控制台填写它的 **AppID** 和 **AppSecret**，启用并保存。不要把普通 QQ 号码、QQ 密码或 NapCat 口令填进这些字段。

如果开放平台要求测试用户、沙箱或 IP 白名单，按该机器人的管理页完成。白名单使用实际网络出口地址；网络或代理出口变化后可能需要更新。WebSocket 是向外建立的连接，不需要为此开放公网端口或部署 Webhook 回调服务器。

创建入口、账号资格与权限以平台当前页面为准，流程参考 [AstrBot 官方指南](https://docs.astrbot.app/platform/qqofficial/websockets.html)及 [QQ 开放平台](https://q.qq.com/qqbot/openclaw/)。密钥只保存在自己的本机配置中，不要放进截图、Issue 或公开备份。

## 绑定自己的私聊

1. 用你的个人 QQ 在机器人的**消息列表私聊**发送：

   ```text
   /fish whoami
   ```

2. 复制回复里「本会话」后的完整内容，形式如下：

   ```text
   连接的平台ID:FriendMessage:官方用户标识
   ```

3. 返回 DSWhale「QQ 连接」，将完整内容粘贴到「官方机器人私聊会话 ID」，保存。

官方用户标识是区分大小写的 OpenID，**不是普通 QQ 号码**。不要改写它，也不要填写群聊或频道会话。应用会核对平台类型、实例和已收到的消息列表私聊记录；不会把第一个发消息的人自动认作主人。

普通 QQ 绑定保留在原位置。两路私聊各自授权、各自保存会话与记忆，不会自动合并聊天或把两个身份认作同一个人。主动消息只发往「主动消息发送到」选定的渠道；停用任一路都要输入对应确认文字。

## 配置模型并验证

1. 在「模型与记忆」打开模型配置，添加供应商、密钥和聊天模型。已有模型沿用原配置，无需重新填写。
2. 为长期记忆配置 Embedding 模型并检查 LivingMemory；已有记忆库继续使用原模型和维度。
3. 回到 QQ 私聊发送「你好」，确认有正常回复，再发送 `/fish status` 检查主人绑定。
4. 需要视频功能时，在 B站页面开启整合并单独登录鱼的 B站账号，按 [B站指南](bilibili.md)配置。
5. 上述步骤通过后，再在连接选项开启主动互动，设置免打扰、每日预算与未回复上限。先用较低频率验证实际送达。

## 功能边界

- 私聊、人格、长期记忆、视频理解、B站笔记可使用。主动聊天和视频推荐可向绑定的私聊提交，但是否送达取决于官方机器人的权限与消息限制。
- 官方发送接口未必提供可核验的送达结果。结果不明确会保留为「未确认」，计入预算，不自动重发；不能据此断言对方已收到或已读。
- 官方接口不能修改普通 QQ 的个性签名或发布 QQ 空间；这些开关在官方模式不提供。
- 主人专属功能只作用于绑定的私聊。群聊功能由 AstrBot 单独配置，不共享主人权限。
- 停止对话服务会断开由它管理的官方接口，个人 QQ 不受影响。电脑休眠、断网或关机后后台任务无法继续。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 创建成功，但无法进入私聊 | 核对开放平台的扫码聊天入口、测试用户/沙箱与可用范围。 |
| 保存绑定时报错 | 复制完整 `/fish whoami` 本会话，确认来自已启用的 QQ 官方 WebSocket 机器人和消息列表私聊。 |
| 配置已保存，但仍显示等待连接 | 在机器人配置里检查启用状态、凭据、网络出口及平台要求的白名单。保存配置不等于网关已经连通。 |
| 能回复，但主动消息没收到 | 先检查主动开关、安静时段、预算和平台权限。未确认的消息不会自动重发，不要靠反复重启尝试绕过限制。 |
| QQ 已连接但没有模型回复 | 检查模型供应商、具体模型、余额和工具调用支持，连接状态与模型可用性分别判断。 |
| 想改签名或发空间 | 这些功能仅通过已绑定的[普通 QQ 小号](qq-napcat.md)执行；不必停用官方连接，只需保留并启用小号连接。 |

官方接入避免了普通 QQ 协议注入，不等于可以绕过平台规则或保证账号永不受限。主动消息能力可参考 [腾讯维护的 QQBot 项目](https://github.com/tencent-connect/openclaw-qqbot/blob/main/README.zh.md)，具体以自己的机器人权限和平台实际返回为准。
