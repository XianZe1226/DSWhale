# 架构与交付边界

DSWhale 是 AstrBot 插件与安装工具，QQ 经安装者独立配置的 NapCat/OneBot 接入，模型与聊天由 AstrBot 提供，长期记忆由固定版本 LivingMemory 管理。

- 一个绑定主人和完整私聊 UMO，群和其他用户不能管理主动活动或读取私人笔记。
- 普通聊天使用可配置人格，长期记忆由 LivingMemory 管理。自主活动通过只读接口读取同一会话的记忆，视频观察独立保存。
- SQLite 保存预算、任务、投递结果和观察。暂停、安静时段、每日预算、未回复上限、去重和不确定发送不重放同样适用于 B站推荐。
- 显式标准视频链接经受限 yt-dlp/FFmpeg 路径读取；完整 B站工具经固定 Node22 sidecar 适配 dsh-bili-whale0.4.6。手动工具保留完整能力，自动公开写入需授权或审批。
- QQ 自然语言选题走串行后台队列；完成后保存日记与一条汇报，追问只读现成笔记。默认先读文字，短视频才能抽帧，抽样不能宣称完整观看。
- 一键安装准备隔离 Python 环境、Node 和页面依赖；QQ/模型/B站认证由本人操作。数据始终留在 `.runtime/astrbot/data`，发行包不包含运行环境和个人配置。
- AGPL 整合代码与随包 MIT 上游各自保留原声明，不分发 QQ/NapCat 程序。Windows10+x64 与 Mac 为安装目标，开发与测试说明见 CONTRIBUTING.md。
