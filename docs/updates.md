# 应用更新与恢复

DSWhale 统一管理桌面程序、AstrBot 内核和运行环境的兼容版本。AstrBot 控制台用于配置模型、平台和插件；内核更新与重启请回到 DSWhale 操作。

## 更新桌面程序

1. 在「应用设置」点击检查更新，选择稳定版或 Alpha 预览版通道。
2. 查看目标版本、兼容组件和配置变化说明，再下载安装包。检查和下载均由按钮触发，不会在后台自行更新。
3. 点击安装。应用会停止自己管理的服务，自动备份数据，再打开已校验的系统安装程序。Windows、macOS 和 Linux 都可能需要你完成系统确认；macOS 按磁盘映像提示安装，Linux 使用系统软件安装工具。
4. 安装完成后重新打开 DSWhale。应用会准备对应运行环境并体检，完成后再手动启动服务。

从 0.3.0a2 或更早版本升级时，需要先从 [Releases](https://github.com/XianZe1226/DSWhale/releases)下载安装本版，再在「运行环境」完成准备。内置更新入口从本版开始提供。

更新器校验发布清单签名、文件大小和 SHA-256，不接受任意下载地址。发布清单的签名用于验证更新来源，**不等于 Windows 发布者签名或 Apple 公证**。当前 Alpha 安装包的系统签名状态以发布页说明为准。

## 失败或中断

下载中断可以重试，已经下载的部分会在来源支持时续传。校验不符的文件不会安装。

如果更新时意外退出，再次打开后会显示未完成步骤。先按界面完成安装、修复环境或回退；恢复过程完成前不会自动启动对话服务。只打开了安装器，并不代表更新已经成功。

可回退时，「应用设置」会显示保留的上一版安装包及恢复入口。默认回退程序版本并保留现有数据。若发布说明要求同时恢复旧数据，需另外确认；恢复前还会备份当前数据。新版本产生的聊天不会自动合并进旧快照。

## 自动备份

「应用设置」显示准备升级、导入或恢复时创建的自动备份，可按时间选择恢复。每次恢复都会先保存当前数据，完成后保持服务停止，供你检查配置。

删除操作将备份移到系统废纸篓或回收站，不会直接清空它。备份包含账号配置、密钥、人格、聊天和记忆，且不加密，请勿公开分享。

LivingMemory 和表情包的独立更新仍在「模型与记忆 → 插件管理」，不需要等 DSWhale 发版。AstrBot 内核随 DSWhale 的兼容版本一起管理，不单独升级。
