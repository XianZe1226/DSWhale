# 应用更新与恢复

DSWhale 统一管理桌面程序、AstrBot 内核和运行环境的兼容版本。AstrBot 控制台用于配置模型、平台和插件；内核更新与重启请回到 DSWhale 操作。

## 更新桌面程序

应用启动并完成本机恢复检查约 30 秒后，会自动检查官方新版本，此后每 6 小时检查一次；需要保持应用运行，唤醒后会延后检查，避免连续请求。检查沿用你选择的稳定版或 Alpha 通道，只获取并验证发布信息，不会自动下载、安装或重启服务。网络失败不会弹窗，可随时手动重试；已发现但尚未下载的版本会继续检查较新发布；网络异常会保留原记录。已下载、下载中或未完成恢复的更新会保留，等待你继续处理。

1. 「应用设置」发现新版后，只显示一个「更新」按钮。点击后开始下载，页面显示实际进度、已下载大小与当前步骤；连接服务器、校验和备份期间会显示正在处理的提示。
2. 下载和校验完成后，会直接提示「覆盖安装」。选择「稍后」会保留已校验的安装包，不停止服务；下次点击「更新」即可继续。
3. 确认覆盖安装后，应用会停止自己管理的服务并自动备份。Windows 沿用当前安装目录，直接进入升级安装，不再要求选择位置；macOS 和 Linux 按系统安装程序的提示覆盖原应用。
4. 完成安装后重新打开 DSWhale，等待运行环境准备和体检，再手动启动服务。已有模型供应商、模型选择、凭据、人格、聊天、记忆与 QQ 设备数据保留，无需重新导入备份。

从 0.3.0a4 或更早版本升级时，需要先从 [Releases](https://github.com/XianZe1226/DSWhale/releases)下载安装本版，再在「运行环境」完成准备。0.3.0a9 及更早桌面版首次更新时仍使用旧界面；安装新版后，后续更新使用上述流程。

更新器校验发布清单签名、文件大小和 SHA-256，不接受任意下载地址。发布清单的签名用于验证更新来源，**不等于 Windows 发布者签名或 Apple 公证**。当前 Alpha 安装包的系统签名状态以发布页说明为准。

## 失败或中断

下载中断可以重试，已经下载的部分会在来源支持时续传。校验不符的文件不会安装。

如果更新时意外退出，再次打开后会显示未完成步骤。先按界面继续更新或修复环境；恢复过程完成前不会自动启动对话服务。只打开了安装器，并不代表更新已经成功。

更新页面不提供版本回退按钮。更新前备份与已验证的安装文件仍保存在本机，更新失败不会自动恢复旧数据。需要人工恢复时，请先保留当前数据与原备份；新版本产生的聊天不会自动合并进旧快照。

## 自动备份

「应用设置」显示准备升级、导入或恢复时创建的自动备份，可按时间选择恢复。每次恢复都会先保存当前数据，完成后保持服务停止，供你检查配置。

删除操作将备份移到系统废纸篓或回收站，不会直接清空它。备份包含账号配置、密钥、人格、聊天和记忆，且不加密，请勿公开分享。

LivingMemory 和表情包的独立更新仍在「模型与记忆 → 插件管理」，不需要等 DSWhale 发版。AstrBot 内核随 DSWhale 的兼容版本一起管理，不单独升级。
